Reports & dashboards

Reports are saved queries with grouping and formatting; dashboards are charts built on reports. Both respect the viewer's security.

Report formats

FormatShapeUse for
TabularA flat list of rowsExports, call lists, simple lists. Can't feed most dashboard charts unless row-limited.
SummaryRows grouped by up to 3 fields, with subtotals"Pipeline by stage", "cases by owner"
MatrixGrouped by rows and columns"Opportunity amount by owner × quarter"
JoinedSeveral blocks, each from its own report type, sharing a grouping"Opportunities and cases per account" side by side

The report builder only shows formats implicitly: add a row grouping and it becomes Summary; add a column grouping and it becomes Matrix.

Report types

A report type decides which objects a report can use and which records appear. Standard report types exist for most objects. Create custom report types (Setup → Report Types) when you need custom objects, specific relationships or "without" logic.

Relationship choiceReturnsExample
A with BOnly A records that have at least one B (inner join)Accounts with Opportunities → no accounts without deals
A with or without BAll A records, plus B where it exists (outer join)All accounts, with their opportunities if any

Report types can go up to four objects deep (A → B → C → D). Add fields via lookup ("Add fields related via lookup") to bring in parent fields without adding a level.

"I can't find my field in the report" almost always means the report type's field layout doesn't include it, or the user lacks field-level security. Edit the custom report type's layout to add new fields.

Filters

  • Standard filters: Show Me (My / My team's / All), date field and range (e.g. Close Date = Current FQ).
  • Field filters with operators: equals, not equal, less than, contains, starts with, includes (multi-select), and relative dates like LAST 90 DAYS, NEXT QUARTER.
  • Filter logic: (1 AND 2) OR 3.
  • Cross filters: "Accounts with / without Cases", optionally with sub-filters ("without Cases where Status = Open"). The classic answer to "show me accounts with no activity".
  • Row limit filters: "Top 10 accounts by revenue".
  • Field-to-field filters: compare two fields (e.g. Close Date < Created Date) in the filter panel.

Calculated values

Bucket fields

Group values into categories without creating a field: Annual Revenue into Small (< 1M), Mid (1M–50M), Large (> 50M); or industries into sectors. Up to 5 buckets per report.

Row-level formulas

One per report; calculated per row.

Summary formulas

Calculated on grouped totals. Use PARENTGROUPVAL for percent-of-total and PREVGROUPVAL for period-over-period.

Dashboards

  • Each component (chart, gauge, metric, table) is driven by one source report (summary or matrix, or tabular with a row limit).
  • Up to 25 components per dashboard; dashboard filters (up to 5) apply to all components that share the field.
  • Running user: a dashboard runs as a specified user (everyone sees that user's data) or as the logged-in user (a dynamic dashboard — each viewer sees their own data). Dynamic dashboards are limited per edition.
  • Dashboards refresh on demand or on a schedule; data isn't live between refreshes.
  • Embed a dashboard on a home or record page with the Dashboard component, or a single report chart on a record page with the Report Chart component (filtered to the record).

Sharing and subscriptions

  • Reports and dashboards live in folders. Share folders with users, groups or roles as Viewer, Editor or Manager. Private reports live in "Private Reports".
  • Subscribe to a report or dashboard to get it by email on a schedule, optionally only when conditions are met (e.g. open P1 cases > 0).
  • Report results always respect the viewer's record and field access, except dashboards running as a fixed user.
