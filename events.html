Platform Events & Change Data Capture

Events decouple systems: a publisher says "this happened" without knowing who listens. Platform Events carry messages you define; Change Data Capture streams record changes automatically.

  • Events are retained for 72 hours (high-volume events) and each has a Replay ID, so a subscriber that was offline can resume from where it left off.
  • Delivery is at least once and in order per channel — subscribers should be idempotent.
  • Events are not records: you can't query or update them, and they don't count toward storage.

Defining a platform event

Setup → Platform Events → New. Name it like an object (Order_Shipped__e), add custom fields (Text, Number, Checkbox, Date/Time, Long Text). Choose the publish behaviour:

Publish behaviourDeliveredUse when
Publish After CommitOnly if the publishing transaction commitsThe event describes data that must exist (most cases)
Publish ImmediatelyRight away, even if the transaction later rolls backLogging and error reporting — e.g. log a failure that will cause a rollback

Subscribing in Salesforce

Apex trigger

  • Event triggers run in their own transaction as the Automated Process user (configurable with a PlatformEventSubscriberConfig to run as another user and set the batch size).
  • Batches can contain up to 2,000 events.
  • Throw EventBus.RetryableException to have the batch redelivered (up to 9 retries), e.g. when a lock or external system is temporarily unavailable.
  • Monitor subscribers in Setup → Platform Events → the event → Subscriptions (suspend, resume, see the last processed replay ID).

Flow

A platform event–triggered flow starts once per event message; $Record is the event. Good for simple reactions (create a task, update a record).

LWC

Subscribing from outside: Pub/Sub API

The Pub/Sub API is a gRPC API (HTTP/2, Avro-encoded payloads) for publishing and subscribing to platform events and CDC from external services. It replaces CometD/Streaming API for new work.

  • Topics: /event/Order_Shipped__e, /data/AccountChangeEvent, /data/ChangeEvents (all CDC-enabled objects), or a custom channel /data/My_Channel__chn.
  • Subscribe is pull-based flow control: the client requests N events at a time.
  • Store the last processed replay ID and pass it with ReplayPreset.CUSTOM when reconnecting.
  • Fetch the Avro schema with GetSchema using the event's schema ID.
  • Salesforce publishes sample clients in Java, Python, Go and Node.js.

Change Data Capture

Setup → Change Data Capture: select objects (standard and custom). Salesforce then publishes a change event for every create, update, delete and undelete: AccountChangeEvent, Invoice__ChangeEvent.

The change event header

FieldMeaning
entityNameObject, e.g. Account
changeTypeCREATE, UPDATE, DELETE, UNDELETE, or GAP_* / GAP_OVERFLOW when details aren't available
recordIdsRecords affected (several when changes are batched)
changedFieldsFields changed in an update
commitTimestamp, commitNumber, transactionKey, sequenceNumberOrdering and grouping within a transaction
changeOrigin, commitUserWhich client/user made the change

The event body contains only the fields that changed (plus the header) for updates; all non-null fields for creates.

CDC vs platform events vs triggers: CDC is automatic and ideal for keeping an external copy (data warehouse, search index) in sync. Platform events are for business messages you design ("Order Shipped"). Apex triggers on the object itself are synchronous and part of the saving transaction; CDC triggers run afterwards, separately, so they can't block or alter the save.

Testing

Allocations and monitoring

  • Publishing and delivery have hourly/daily allocations by edition (higher with add-on licences). Check /limits (HourlyPublishedPlatformEvents, DailyDeliveredPlatformEvents, CDC equivalents).
  • Delivery to Apex triggers and flows doesn't count against the external delivery allocation.
  • Use Event Relays to forward events to Amazon EventBridge without middleware.
  • Custom channels group events and add filters (PlatformEventChannel, enriched fields for CDC).
