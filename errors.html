Gotchas

"It works for me"

You're a System Administrator with View All Data. Test as the user (Login As) and walk the security layers.

15- vs 18-character IDs

Spreadsheets compare case-insensitively, so 15-char IDs collide. Use CASESAFEID(Id) in a formula or the 18-char ID from the API.

Hardcoded IDs and URLs

Differ between orgs. Use DeveloperName lookups, custom metadata, Named Credentials, Url.getOrgDomainUrl().

Time zones

Datetimes are stored in UTC. Date values derived from Datetime use the running user's zone; scheduled jobs use the org's default time zone.

Checkboxes are never null

But Booleans in Apex can be. if (myBool) with null throws.

Formula fields aren't recalculated in Apex memory

After changing a field in Apex, formula values on the in-memory record are stale until re-queried (or call Formula.recalculateFormulas(records)).

Sandbox emails

New sandboxes send "System email only". Flows "work" but no email arrives until deliverability is changed.

Trigger order

Multiple triggers on one object run in no guaranteed order. Keep one trigger per object.

Deleting a field deletes its data

After 15 days in the Recycle Bin it's gone for good; export first.

Picklist API value vs label

Code and the API use API values; translations and renames change labels. Compare against API values.

Release surprises

Read release notes and test release updates in a preview sandbox each release.
