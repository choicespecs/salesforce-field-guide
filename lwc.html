Lightning Web Components

LWC is Salesforce's UI framework, built on web standards: custom elements, shadow DOM, ES modules and templates. If you know modern JavaScript, most of LWC is familiar; the Salesforce parts are data access and where components can be placed.

A component is a folder

Folder and file names are camelCase; in markup they become kebab-case with the c- namespace: <c-account-contacts>. Create one with sf lightning generate component --name accountContacts --type lwc --output-dir force-app/main/default/lwc.

Reactivity and decorators

  • All class fields are reactive: assigning a new value re-renders. For objects and arrays, assign a new reference (this.items = [...this.items, x]) — mutating in place isn't tracked unless the field uses @track.
  • @api: public property or method, set by the parent or the page. Treat @api values as read-only inside the component.
  • @wire: reactive data from an adapter or cacheable=true Apex. Assign to a property ({ data, error }) or a function.
  • Getters recalculate on each render — use them for derived values.

Lightning Data Service (no Apex)

LDS reads and writes records through a shared client cache, respects security, and keeps every component showing the same record in sync. Prefer it to Apex for single-record work.

Styling

  • Component CSS is scoped by shadow DOM: it can't leak out, and outside CSS can't reach in.
  • Use the Salesforce Lightning Design System (SLDS) utility classes (slds-p-around_medium, slds-grid, slds-text-heading_small) and base components (lightning-*) so your UI matches the platform.
  • Style base components with styling hooks (CSS custom properties) such as --slds-c-button-brand-color-background, not by targeting their internals.

Debugging

  • Setup → Debug Mode: enable for your user to get unminified framework code and clearer errors (slower; turn it off afterwards).
  • Browser DevTools: components appear as custom elements; use console.log(JSON.stringify(proxy)) to see reactive proxies' values.
  • Apex errors reach the component as error.body.message; throw AuraHandledException for user-friendly messages.
  • Lightning Locker / Lightning Web Security isolate components by namespace; some global APIs are restricted.
