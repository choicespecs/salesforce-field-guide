Learning

  • Trailhead: free modules and projects with hands-on challenges checked against a practice org. Search for the trails that match the chapter you're reading.
  • Developer Edition signup: a free, permanent org.
  • Salesforce Developers Blog and Salesforce Admins: feature explanations from product teams.
  • trailheadapps on GitHub: complete sample apps (LWC Recipes, Apex Recipes, Dreamhouse, Ebikes) showing current best practice.
  • Trailblazer Community and Salesforce Stack Exchange: questions and answers.

Tools worth installing

  • VS Code + Salesforce Extension Pack (Expanded): Apex language server, LWC support, SOQL builder, org browser, debugger.
  • Salesforce CLI (sf).
  • Apex Log Analyzer (VS Code extension): flame charts and timing for debug logs.
  • Salesforce Code Analyzer: static analysis (PMD, ESLint and more) — sf plugins install code-analyzer.
  • Salesforce Inspector Reloaded (browser extension): quick SOQL, field API names, data export from any page.
  • Data Loader.
