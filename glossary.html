Glossary

Platform vocabulary in one place. Type to filter.

A
Agentforce
Salesforce's platform for building AI agents that take actions.
Anonymous Apex
Apex run once without saving a class (Developer Console or sf apex run).
Apex
Salesforce's server-side, Java-like programming language.
Apex managed sharing
Sharing records programmatically by inserting rows into __Share objects.
Apex REST
Custom REST endpoints written in Apex with @RestResource.
API name
The name used in code and the API (Invoice__c), as opposed to the label shown to users.
API version
Versioned platform behaviour; each release adds one (e.g., 64.0). Set per class/component.
AppExchange
Salesforce's app marketplace.
Aura
The older Lightning component framework.
AuraEnabled
Annotation exposing an Apex method to Lightning components.
B
Batch Apex
Async Apex that processes large record sets in chunks, each with fresh limits.
Before-save flow
A record-triggered flow that updates the triggering record before it's saved, without DML.
Bulk API 2.0
An asynchronous REST API for loading and extracting large volumes of records.
Bulkification
Writing code that handles many records at once without per-record queries or DML.
Business hours
Working-hour calendars used by escalation rules, milestones and BusinessHours in Apex.
C
CDC
Change Data Capture: an event stream of record changes.
Change Data Capture
Streaming record changes as events for external systems to consume.
Change set
A UI-based bundle of metadata deployed between connected orgs.
Code coverage
Percentage of Apex lines executed by tests; 75% required for production deploys.
Composite API
A REST resource that runs several requests in one call, optionally all-or-none.
Connected App / External Client App
An OAuth client definition for external systems calling Salesforce.
Custom Metadata Type
Deployable configuration records (__mdt).
Custom permission
A named flag granted through permission sets and checked in formulas, Flow, Apex and LWC.
Custom Setting
Cached configuration data, optionally per user or profile.
D
Data 360
Salesforce's data unification platform, formerly Data Cloud.
Data model object (DMO)
A harmonised entity in Data 360 that ingested data is mapped to.
Data skew
Too many child records on one parent, or records owned by one user, causing locks and slowness.
Debug log
A trace of a transaction's execution, queries, DML and limit usage.
Destructive changes
A manifest listing metadata to delete during a deployment.
Dev Hub
The org that owns your scratch orgs and packages.
DML
Data Manipulation Language: insert, update, upsert, delete, undelete, merge.
Dynamic Forms
Placing individual fields on Lightning record pages with visibility rules.
E
Einstein Trust Layer
Safeguards around generative AI calls: masking, zero retention, toxicity checks, audit.
Entitlement
Defines the support a customer is owed, with milestones like response times.
Experience site
A portal or website built with Experience Cloud.
External Credential
The authentication part (OAuth, API key, etc.) referenced by Named Credentials.
External ID
A field marked as another system's key; indexed and usable for upsert.
External Object
A virtual object (__x) whose data lives outside Salesforce.
F
Field-history tracking
Recording old and new values of selected fields.
Finalizer
Code attached to a Queueable that runs after it finishes, even if it failed.
Flow
Salesforce's declarative automation tool.
FLS
Field-Level Security: whether a user can read or edit a field.
Formula field
A read-only field calculated from other fields at read time.
G
Global value set
A picklist value list shared by multiple fields.
Governor limits
Per-transaction resource limits enforced by the multi-tenant platform.
H
Hyperforce
Salesforce's infrastructure running on public cloud providers.
I
Implicit sharing
Built-in access, e.g. read access to an Account for owners of its contacts, opportunities or cases.
Instance
The physical server pod your org runs on (e.g., NA123). Visible on trust.salesforce.com.
Integration user
A dedicated, API-only user for a system integration, with minimal permissions.
Invocable method
An Apex method annotated @InvocableMethod so Flow and agents can call it.
J
Junction object
A custom object with two master-detail relationships, used to model many-to-many.
K
Key prefix
The first three characters of a record Id, identifying its object.
Knowledge
Service Cloud's article base.
L
LDS
Lightning Data Service: cached, security-aware record access for components without Apex.
Lead conversion
Turning a Lead into an Account, Contact and optionally an Opportunity.
Lightning App Builder
The drag-and-drop editor for Lightning record, app and home pages.
Lightning Message Service
Publish/subscribe messaging between components on the same page.
Lightning record page
A page built in Lightning App Builder with components, tabs and Dynamic Forms.
Login As
Admin feature to log in as another user to test what they see (must be enabled).
Lookup relationship
A loose link between records; the child keeps its own owner and sharing.
LWC
Lightning Web Components, the standards-based UI framework.
M
Managed package
A namespaced, IP-protected package, usually from AppExchange.
Master-detail relationship
A tight link: the detail inherits sharing from the master and is deleted with it.
Matching rule / duplicate rule
How to detect duplicate records, and what to do when one is found.
Metadata
The configuration that describes your org: objects, fields, layouts, flows, code, permissions.
My Domain
Your org's unique subdomain, e.g. acme.my.salesforce.com.
N
Named Credential
Stored endpoint and auth reference for outbound callouts.
Namespace
A prefix (like SBQQ__) on a managed package's components.
O
Object
A database table. Standard objects ship with Salesforce; custom objects end in __c.
Omni-Channel
Service Cloud routing that pushes work to available agents.
Opportunity stage
A step in the sales process with an associated probability.
Order of execution
The fixed sequence of steps Salesforce runs when a record is saved.
Org
Your company's instance of Salesforce: its data, metadata, users and configuration.
OWD
Organization-Wide Defaults: the baseline record access for each object.
P
package.xml
A manifest listing metadata to retrieve or deploy.
Page layout
Controls the fields, related lists and buttons on a record page.
Permission set
An additive bundle of permissions assignable to any number of users.
Permission Set Group
A bundle of permission sets assigned as one, with optional muted permissions.
Person Account
An Account that represents an individual, combining Account and Contact.
Platform Event
A custom event message (__e) for publish/subscribe.
Polymorphic field
A lookup that can point to several object types, such as WhoId, WhatId or OwnerId.
Profile
Each user's single base set of settings and (legacy) permissions.
Prompt template
A reusable prompt grounded in Salesforce data, built in Prompt Builder.
Pub/Sub API
A gRPC API for publishing and subscribing to platform events and CDC.
Public group
A named set of users, roles and other groups used in sharing and queues.
Q
Queue
A holding owner for records (Leads, Cases, custom objects) that a group of users works from.
Queueable
An async Apex job that takes complex parameters and can be chained.
R
Record
A row in an object.
Record type
Lets one object have different business processes, picklist values and layouts.
Release
One of three annual platform upgrades: Spring, Summer, Winter.
Replay ID
The position of an event in the event bus, used to resume a subscription.
Restriction rule
Limits which records a user sees even when sharing would grant access.
Role hierarchy
Grants managers access to records owned by users below them.
Roll-up summary
A parent field that aggregates child records in a master-detail relationship.
S
Salesforce DX
Source-driven development tooling: the sf CLI, project format, scratch orgs and packaging.
Sandbox
A copy of production for development or testing.
Schedulable
Apex that runs on a cron schedule.
Scheduled path
Part of a record-triggered flow that runs at a time relative to a date field or the trigger.
Scratch org
A disposable org created from source and a config file.
Selective query
A query whose filter uses an index and returns few enough rows for the optimiser.
Sharing rule
Extends record access to groups or roles based on owner or criteria.
SLDS
Salesforce Lightning Design System: CSS framework and design guidelines.
sObject
Apex's generic type for any record. Account, Contact and Invoice__c are all sObjects.
SOQL
Salesforce Object Query Language — queries records from one object and its relationships.
SOSL
Salesforce Object Search Language — full-text search across objects.
System mode
Apex's default: ignores the running user's object, field and (without 'with sharing') record permissions.
T
Test class
An @IsTest class that verifies Apex and provides code coverage.
Test level
Which tests run in a deployment: NoTestRun, RunSpecifiedTests, RunLocalTests, RunAllTestsInOrg.
Topic (Agentforce)
A job an agent can do, with instructions and the actions it may use.
Trailhead
Salesforce's free learning platform.
Transaction
A unit of work that succeeds or rolls back as a whole and shares one set of limits.
Trigger
Apex that runs before or after DML on an object.
U
Unified profile
A Data 360 record merging one person's data from many sources via identity resolution.
Unlocked package
A versioned, installable bundle of your own metadata.
Upsert
Insert or update in one operation, matched by Id or an External ID.
User mode
Running queries or DML with the user's permissions enforced (WITH USER_MODE, as user).
V
Validation deploy
A check-only deployment that runs tests without saving changes; can be quick-deployed later.
Validation rule
A formula that blocks a save when it evaluates to true.
Visualforce
The Classic-era page framework.
W
Wire adapter
A reactive data source for LWC, such as getRecord or a cacheable Apex method.
