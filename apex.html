Apex language

Apex is a strongly typed, object-oriented language with Java-like syntax that runs on Salesforce's servers. It has the database built in: queries and DML are part of the language. Every line runs inside governor limits.

Access modifiers

private (default), protected, public (within the namespace), global (across namespaces — needed for managed packages, REST resources, and some interfaces).

Sharing keywords

with sharing, without sharing, inherited sharing. See Security. Always declare one.

Static

Statics live for one transaction only — there's no state between requests. Use them for caches and recursion flags within a transaction.

Class size

A single class can be up to 1 million characters; the whole org can hold 6 MB of Apex (excluding tests and managed packages).

Exceptions

You can't catch limit exceptions. System.LimitException ends the transaction. Prevent them by bulkifying and checking Limits methods.
